Telegram Integration

Powers security alerts (wrong-password/lockout/login events, for every account — not just the one involved) and forgot-password reset links. Create a bot via @BotFather to get a bot token; each relevant user then messages that bot once and uses a helper like @userinfobot to find their own numeric chat ID, which is set on their row on the Users page.

Off by default so adding a bot token alone doesn't start sending messages.
